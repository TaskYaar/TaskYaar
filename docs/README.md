# Docs

Short, living documents. If code and docs disagree, fix the doc in the same PR.

- `decisions.md`: log of key choices and why (date, decision, reason, alternatives)
- `data-model.md`: tables and relationships
- `state-machine.md`: allowed transitions for Task, Booking and Payment, including cancel and dispute rules
- `api.md`: conventions (versioning, errors, pagination) plus link to generated docs
- `runbook.md`: deploy, rollback, restore backup, payment incident steps
- `git-workflow.md`: branches, commit messages, PR checklist
- `legal/`: terms, privacy policy, grievance officer process (required for launch in India)
